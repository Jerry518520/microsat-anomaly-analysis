# 10. scikit-learn版本差异导致IsolationForest结果漂移

**日期**: 2026-05-07
**发现人**: Claw (AI) + 李冰杰
**状态**: 已确认根因，待统一版本

## 现象

同一份数据 (`segments_18d.csv`)、同一段代码、同一个 `random_state=42`，不同时间运行 `fair_comparison_v2_segments_c02.py` 得到了不同的 Baseline F1：

| contamination | 5月5日结果 | 5月7日结果 | 差值 |
|:---:|:---:|:---:|:---:|
| 0.1 | 0.2840 | 0.2573 | -0.027 |
| 0.2 | 0.2996 | 0.2832 | -0.016 |
| 0.3 | 0.3262 | 0.3273 | +0.001 |
| 0.4 | 0.4000 | 0.3812 | -0.019 |
| 0.45 | 0.4293 | 0.3889 | -0.040 |

所有 c 值的 F1 都变了，不是个别点的随机波动，而是系统性偏移。

## 根因

**scikit-learn 版本不同：**

| 环境 | sklearn版本 | Baseline c=0.2 F1 |
|------|-----------|:---:|
| 5月5日运行 | 1.8.0 | 0.2996 |
| 5月7日 venv 实际 | 1.7.2 | 0.2832 |
| 5月7日装回 1.8.0 后 | 1.8.0 | **0.2996** ✅ |

**验证过程：**
1. 先用 sklearn 1.7.2 运行 → 结果与5月5日 JSON 不符
2. 用 `pip install scikit-learn==1.8.0` 装回 lock 版本
3. 重新运行 Stage0 sweep 全部 9 个 c 值 → **逐个精确匹配** 5月5日 JSON（小数点后4位完全一致）
4. 确认因果关系：**sklearn 1.7→1.8 的 IsolationForest 内部树分裂逻辑有变化**

**非版本因素（已排除）：**
- 数据文件未变（segments_18d.csv 修改时间 5月5日14:08，md5一致）
- 代码逻辑未变（同一个 random_state=42, n_estimators=100）
- numpy/pandas 版本未变

## 影响范围

- 所有使用 IsolationForest 的实验结果都受影响
- `random_state=42` 在不同 sklearn 版本下产生不同的树结构
- 不影响：规则兜底（纯统计规则与 sklearn 无关）、数据预处理、特征提取

## 建议

1. **锁定版本**: 在 README 或实验脚本顶部标注 `scikit-learn==1.8.0`
2. **统一环境**: 所有实验运行前确认 `python -c "import sklearn; print(sklearn.__version__)"` 输出 1.8.0
3. **poetry.lock 已锁定 1.8.0**: 正常使用 `poetry install` 即可，问题出在有人手动 pip install 了其他包导致依赖降级

## 对当前实验数据的影响

| 阶段 | 方法 | sklearn 1.8.0 | sklearn 1.7.2 |
|------|------|:---:|:---:|
| ① Baseline | 全局IF(c=0.2) | **0.300** | 0.283 |
| ② 分通道 | 分通道IF(c=0.2) | **0.538** | 0.484 |
| ③ 规则融合 | IF+OR+规则(c=0.2) | **0.568** | 0.563 |
| ③+threshold | 融合+阈值(0.1) | **0.578** | 0.578 |

- 最终 F1=0.578 两个版本一致（阈值微调抵消了版本差异）
- 报告/PPT 中引用 Baseline 对比数据时，需确认环境版本
