# 实验05: 确定性规则兜底 + 通道自适应融合

日期: 2026-04-27

## 目标
用可解释的统计规则兜底IForest的弱通道，实现"IForest+规则"混合检测。

## 思路变化
实验04证明弱通道IForest的天花板很低(F1<0.3)，再调参也没用。核心洞察：**IForest是"黑箱概率"，规则是"白箱确定性"**——两者互补：
- IForest擅长: 捕捉高维复杂模式（强通道CADC0874等）
- 规则擅长: 给出明确边界（超出3σ就是异常，不用猜）
- 融合策略: **强通道信IForest，弱通道信规则**——各用各的优势

## 方法
- sklearn版本: 1.7.2（运行时环境，见实验10关于版本漂移的说明）

1. **统计阈值规则**: 3σ(正态假设) + IQR(非参数)，从训练集算每个通道每个特征的阈值
2. **5种融合方案对比**:
   - A: IF正常+规则异常→异常（降漏报）
   - B: 强通道IF + 弱通道规则
   - C: 时序连续性平滑
   - D: IF AND 规则（降误报）
   - E: IF OR 规则（降漏报）
3. **最终方案**: 分通道最优c + 通道自适应融合

## 结果

### 融合方案对比 (ws=20)
| 方案 | 窗口F1 | 段级F1 | 段级P | 段级R |
|------|--------|--------|-------|-------|
| IForest only | 0.368 | 0.268 | 0.197 | 0.418 |
| 规则 only | 0.225 | 0.097 | 0.094 | 0.100 |
| IF OR 规则 | 0.379 | 0.241 | 0.166 | 0.436 |
| 强通道IF+弱通道规则 | 0.404 | 0.220 | 0.259 | 0.191 |
| 时序平滑 | 0.363 | 0.263 | 0.194 | 0.409 |
| IF AND 规则 | 0.194 | 0.092 | 0.125 | 0.073 |
| **🏆 最终方案** | **0.479** | **0.325** | **0.248** | **0.473** |

### 递进效果
- 段级baseline: F1=0.262
- +滑动窗口+分通道调c: F1=0.268（+2%）
- +规则兜底+通道融合: F1=0.325（+24%）

## 思路反思
1. **规则单独用效果很差**(F1=0.097)，但"弱通道用规则"比"弱通道用IForest"好——规则在IForest力不从心的场景有兜底价值
2. **AND太保守OR太激进**——逻辑运算不是好融合方式，通道自适应才是
3. **分通道最优c是乘数效应**——和规则融合组合后，从0.268→0.325，提升24%
4. **0.325首次突破0.30**，超过段级baseline(0.298)，但离0.35目标还差一步

## 遗留问题
1. 弱通道(CADC0892等)的规则兜底还不够好，规则阈值(3σ+IQR)可能太粗
2. 段级聚合用简单多数投票，是否加权更好？
3. 精确率(0.248)偏低，误报仍多——可以加"连续异常才确认"的后处理
