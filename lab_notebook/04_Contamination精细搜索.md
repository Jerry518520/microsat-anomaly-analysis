# 实验04: Contamination精细搜索

日期: 2026-04-27

## 目标
解决"统一contamination不适应各通道分布差异"的问题。

## 思路变化
IForest的contamination参数直接决定"模型认为多少比例是异常"。9个通道的异常比例和分布各不相同，用同一个c=0.4显然不是最优。思路：**让每个通道自己找最适合自己的异常比例**。

## 方法
- 固定ws=20, step=10
- 全局搜索: c=[0.2,0.25,0.3,0.35,0.37,0.4,0.45,0.5]
- 分通道独立搜索: 同上范围，各通道独立找最优c

## 结果

### 全局最优
- c=0.5时全局SegF1=0.268（比之前c=0.4的0.210提升28%）
- c=0.5意味着"模型认为一半是异常"——实际异常比20%，这个值偏高是因为IForest的contamination不代表精确比例

### 分通道最优
| 通道 | 最优c | F1 | 强弱 |
|------|-------|-----|------|
| CADC0874 | 0.5 | 0.591 | 强 |
| CADC0872 | 0.5 | 0.509 | 强 |
| CADC0873 | 0.5 | 0.474 | 强 |
| CADC0888 | 0.45 | 0.296 | 弱 |
| CADC0894 | 0.5 | 0.284 | 弱 |
| CADC0890 | 0.3 | 0.500 | 弱 |
| CADC0892 | 0.5 | 0.134 | 弱 |
| CADC0886 | 0.2 | 1.000 | 极少样本 |

## 思路反思
1. **强通道(c=0.5, F1>0.47)和弱通道(F1<0.3)差距依然巨大**——不是调参能解决的
2. **弱通道的IForest能力已到天花板**——CADC0892的F1=0.134，再怎么调c也上不去，因为正常/异常数据本身就重叠严重
3. **IForest不是万能的**——对于分布重叠严重的通道，纯无监督方法力不从心
4. **0.268还远不够**，需要另一个"武器"来补弱通道
