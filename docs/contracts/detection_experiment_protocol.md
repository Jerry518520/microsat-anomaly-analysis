# 毕业设计检测实验规程

规程版本为 graduation-confirmation-v1。2026-11-06 在本轮正式评分前固定。

## 数据与适用范围

使用 18d-canonical-v1 的全部 18 维特征。现有划分为拟合 1275 段、验证 319 段、已查看测试基准 529 段。三个集合必须无重叠，合计 2123 段。按段号排序。不得修改原始特征或历史结果。

529 段已在历史开发中反复查看。本次结果属于基准复核。通道划分后的测试数小于 30 时，标记样本较少。

## 同配置对照

所有实验 IF 使用 100 棵树、max_samples 上限 128、随机种子 42、单线程。实际抽样量为拟合行数与 128 的较小值。所有 IF 共用同一个 contamination。候选依次为 0.05、0.20、0.35。以分通道 IF 在验证集上的总体 F1 选 contamination。并列时保留候选顺序靠前者。

规则复用 EngineeringJudge 的规则计算。每个特征的 3σ 或 IQR 违例只计一次。规则阈值只用拟合集计算。k 候选依次为 1、2、3、4。按纯规则验证 F1 选择。并列时取较小值。

对照包括全局 IF、分通道 IF、纯规则、AND、OR、自适应门控、软融合。AND 和 OR 共用分通道 IF 与纯规则输出。逐通道门控按验证 F1 选择，候选顺序为 rule、AND、if、OR。某通道验证数小于 5 或只有一种标签时，固定使用 rule。拟合数小于 5 的通道，规则与 IF 均使用全局拟合组件，并记录回退。

软融合的 IF 分数用该模型拟合分数的经验分布转成百分位。规则分为违例数除以 18。软融合为 alpha 乘 IF 百分位加 1-alpha 乘规则分。alpha 候选为 0.25、0.50、0.75。阈值候选为 0.25、0.50、0.75。按 alpha 优先、阈值次优先枚举。验证 F1 并列时保留首项。最终比较使用大于等于阈值。

当前工程冻结门控单独报告。它沿用历史通道参数，不能并入同配置消融，也不进入嵌套稳定性评价。

## 内部稳定性

只使用官方训练部分的 1594 段。外层使用按异常标签分层的 3 折，打乱，种子 42。每折外层训练部分再按异常标签分层划分 80% 内层拟合和 20% 内层验证，种子为 43 加折号。所有参数和通道算子只在内层选择。选定后，使用完整外层训练部分重新拟合，再对外层留出部分评分。保存每折成员、配方和逐段预测。

小样本通道沿用上述全局回退规则。不得复制样本或用外层标签选择模型。外层折仍来自同一数据集，不能称作独立外部验证。

## 独立评分

保存段号、通道、真值、规则违例、规则标签、IF 标签、门控算子、最终标签及适用连续分。独立评分入口只读预测文件。混淆矩阵整数完全一致，P、R、F1、Accuracy、MCC 和适用 AUC 的复算误差不超过 1e-12。

全局 IF、分通道 IF 使用负 decision_function 计算 ROC-AUC 与 AP。纯规则使用违例数。软融合使用融合分。AND、OR 和门控只报告分类指标。AP 按 average_precision 定义报告，避免与梯形积分的 PR-AUC 混称。单类通道的 ROC-AUC 记为不适用。

使用通道为整簇的 bootstrap，种子 42，重采样 2000 次，每次有放回抽取 9 个通道。每个被抽取通道保留全部段。报告 F1 的 95% 百分位区间，以及门控减规则、门控减分通道 IF 的配对 F1 差区间。该区间反映通道间变化。仅有 9 个通道，区间应与逐通道结果共同解读。

重复运行应产生相同预测。保留输入、规程、源码、预测文件的 SHA-256 和依赖版本。结果不能以 F1 提升作为通过条件。
