## 条目1: OPS-SAT 9通道物理含义与异常特征

### 通道分类
OPS-SAT卫星遥测数据集(OPS-SAT-AD)包含9个遥测通道，分为两类：

**强通道（磁力计，3轴）：**
- CADC0872 = I_B_FB_MM_0（磁力计X轴）：测量地磁场X方向分量
- CADC0873 = I_B_FB_MM_1（磁力计Y轴）：测量地磁场Y方向分量  
- CADC0874 = I_B_FB_MM_2（磁力计Z轴）：测量地磁场Z方向分量

磁力计异常含义：磁干扰、磁力矩器故障、姿态控制系统异常、地磁环境变化。
磁力计是OPS-SAT ADCS系统的核心姿态感知传感器，3轴磁力计提供卫星相对于地磁场的方向信息。

**弱通道（光电二极管，6角度）：**
- CADC0884 = 光电二极管1角度
- CADC0886 = 光电二极管2角度
- CADC0888 = 光电二极管3角度
- CADC0890 = 光电二极管4角度
- CADC0892 = 光电二极管5角度
- CADC0894 = 光电二极管6角度

光电二极管异常含义：姿态偏差、传感器遮挡、光照条件变化、传感器故障。
光电二极管用于测量太阳方向，辅助姿态确定。6个不同安装角度提供冗余测量。

### 异常类型
OPS-SAT-AD数据集中标注了4种异常类型：
1. **Unusual shapes**（异常形状）：信号波形出现非典型模式
2. **Peaks**（尖峰）：信号突然出现短暂的高幅度偏移
3. **Zero values**（零值）：传感器读数归零，可能指示传感器故障或数据丢失
4. **Gaps**（数据间隙）：信号中出现长时间的数据缺失

CADC0874通道异常以"长数据间隙(long data gaps)"为主。

### 数据来源
通道物理含义来源于：Ruszczak et al., "An expert-annotated dataset for anomaly detection in satellite telemetry", Scientific Data (Nature), 2025. DOI: 10.1038/s41597-025-05035-3
数据集由3名ESA航天器操作工程师和2名ML专家标注。

## 条目2: OPS-SAT异常检测实验结果（Isolation Forest）

### Baseline结果
- 算法：Isolation Forest (sklearn默认参数)
- 段级F1分数(SegF1): 0.262
- 这是官方benchmark复现结果，作为对比基准

### 通道级别性能
磁力计通道（强通道）F1显著高于光电二极管（弱通道）：
- CADC0874(磁力计Z): F1=0.591 (最佳单通道)
- CADC0872(磁力计X): F1>0.47
- CADC0873(磁力计Y): F1>0.47
- 光电二极管通道: F1较低，异常信号弱

### 优化路径与结果
| 实验 | 方法 | SegF1 | 说明 |
|------|------|-------|------|
| 1.4 | 滑动窗口ws=20 | 0.210 | 窗口大小20段 |
| 1.5 | contamination=0.5 | 0.268 | 全局污染率搜索 |
| 1.6 | 分通道最优c+规则兜底 | 0.325 | 首次突破0.30 |
| 1.7 | 融合方案G | 0.342 | 强IF+弱规则OR+段级投票 |
| 1.8 | 投票阈值th=0.25 | 0.418 | 融合G+投票，P=0.275 R=0.873 |
| 1.9 | IForest子采样psi=128 | **0.425** | Phase1最优，P=0.278 R=0.900 AUC=0.471 |

### 最优方案细节（方案G + 投票阈值0.25 + 子采样psi=128）
- **强通道处理**：使用Isolation Forest异常检测，子采样大小psi=128（论文AUC 0.67→0.91方向）
- **弱通道处理**：使用3σ/IQR统计规则兜底检测
- **段级投票**：9个通道分别检测，当≥25%的窗口判为异常时标记该段为异常
- **Precision=0.278, Recall=0.900, AUC=0.471**：高召回率，psi从默认256降到128，Recall提升0.027

### 关键发现
1. 磁力计通道异常信号明显强于光电二极管，分通道处理是必要的
2. 全局contamination参数不如分通道独立调参
3. 弱通道用统计规则比IForest效果更好（信号弱时规则更稳定）
4. 投票阈值0.25是最优点：太低噪声多，太高漏检多
5. 相比baseline IForest F1=0.262，提升62%

## 条目3: OPS-SAT ADCS系统架构与故障模式

### ADCS硬件组成（ESA官网确认）
OPS-SAT姿态确定与控制系统(ADCS)包含以下硬件：
1. **陀螺仪**：测量角速度
2. **加速度计**：测量线加速度
3. **磁力计×3**：测量地磁场方向和强度（3轴）
4. **反作用飞轮**：精确姿态控制执行器
5. **磁力矩器×3**：粗姿态控制执行器（通过产生磁矩与地磁场交互产生力矩）
6. **星敏感器**：高精度姿态测量

### 故障模式与RAG解释闭环
异常检测触发后，RAG系统的解释流程：
1. **检测异常**：IForest/规则检测到某通道异常
2. **通道定位**：根据CADC编号确定是磁力计还是光电二极管
3. **类型分类**：判断异常属于4种类型中的哪一种
4. **知识检索**：在知识库中检索该通道/异常类型相关的工程知识
5. **原因解释**：基于检索结果，给出可能的物理原因和工程解释

### 混合部署架构
本项目RAG系统采用混合部署架构：
- **检索本地化**：BGE-M3嵌入模型（ModelScope本地部署，CUDA加速） + FAISS向量数据库，运行在本地，检索毫秒级
- **生成云端化**：LLM(DeepSeek V3.2)通过火山引擎Ark API调用，利用大模型的推理能力
- **优势**：嵌入模型一次编码反复使用，检索延迟低；LLM推理能力强，无需本地部署大模型；火山引擎API响应稳定25-40秒

## 条目4: 数据集统计信息

### OPS-SAT-AD数据集
- **segments文件**: 303,000行×8列, 17.1MB, 9个通道
- **dataset文件**: 2,123段×23列, 18个特征+5元信息列
- **异常比例**: 20.4%
- **训练集**: 1,594段 | **测试集**: 529段
- **标注者**: 3名ESA航天器操作工程师 + 2名ML专家

### 官方Benchmark对比
| 算法 | F1分数 | 说明 |
|------|--------|------|
| AdaBoost | 0.836 | 官方最高(监督学习) |
| IForest | 0.262 | 官方无监督baseline |
| IForest(c=0.2) | 0.433 | 官方调参后 |
| 本项目最优 | 0.425 | 无监督(psi=128)，接近官方调参结果 |

### 特征工程
滑动窗口提取22维特征：
- 统计特征：均值、标准差、最小值、最大值、中位数
- 分布特征：偏度、峰度、四分位距
- 时序特征：一阶差分统计、过零率、能量
- 趋势特征：线性回归斜率、残差
