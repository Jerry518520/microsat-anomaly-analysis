# Streamlit UI 设计方案

## 微小卫星遥测智能异常检测与RAG解释辅助系统 — 交互式展示界面

---

## 一、整体架构

### 页面结构（3页面 + 侧边栏控制）

```
🏠 总览仪表盘 (Dashboard)
📊 异常检测分析 (Detection)  
💬 RAG智能解释 (Explanation)
```

### 技术选型
- Streamlit 1.35+ (st.tabs / st.columns / st.metric)
- Plotly (交互式图表，替代静态matplotlib)
- 现有模块直接import（anomaly_rag_pipeline / utils.visualization）

---

## 五、开发优先级

1. **P0 (5/1晚)**: app.py + dashboard.py — 能跑起来，展示核心指标和图表
2. **P1 (5/2)**: detection.py — 参数调节+实时检测

4. **P3 (5/3)**: 美化+custom.css — 答辩级视觉效果

---

## 六、关键设计决策

1. **用Plotly不用matplotlib** — 交互式，鼠标悬停显示数值，答辩演示效果更好
2. **侧边栏集中控制** — 所有参数调一个地方，主区域全部是图表
3. **预计算+缓存** — @st.cache_data缓存检测结果，RAG按需调用
4. **深色主题** — 航天科技感，异常红色更醒目
5. **不重复造轮子** — 直接import现有anomaly_rag_pipeline和visualization模块
