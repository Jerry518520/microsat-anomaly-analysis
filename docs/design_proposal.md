# OPS-SAT 遥测异常诊断系统 — 前端视觉设计方案

> 版本: v2.0 | 日期: 2026-06-02 | 状态: 待确认

---

## 一、设计定位

**签名概念**: **"玻璃座舱"** — 现代航天器驾驶舱的真实显示系统。

不是"一个暗色仪表盘"，而是：你坐在 OPS-SAT 的地面控制台前，透过磨砂玻璃面板，看到卫星遥测数据像座舱 HUD 一样投射在你面前。

**签名时刻**: 任何人打开这个系统的第一秒，会看到——
> 9 个遥测通道的波形像示波器磷光一样扫过屏幕，异常通道突然闪烁红色脉冲，整个界面像一台正在工作的航天器显示终端。

**目标用户**: 卫星运维工程师 — 长时间盯屏，需要"扫一眼就知道有没有问题"。

**灵感来源**:
- Boeing 787 玻璃座舱显示器 (实际航空 HUD)
- NASA Space Shuttle 座舱 CRT 显示器
- 《异形》系列电影的 Nostromo 飞船电脑界面 (Jordan Cronenweth 风格)
- F-35 头盔显示系统 (HMDS)
- 现代示波器 (Keysight/ Tektronix) 的界面设计

### 2.2 语义色规则

| 状态 | 颜色 | 视觉处理 |
|------|------|---------|
| **NOMINAL** | `#34D399` | 柔和绿光 + 微弱呼吸脉冲 |
| **SELECTED** | `#00E5FF` | 磷光青 + 玻璃反光叠加 |
| **CAUTION** | `#FBBF24` | 琥珀黄 + 左边框标记 |

| **CRITICAL** | `#FF2D55` | 品红 + 全卡片脉冲辉光 |
| **OFFLINE** | `#3A4558` | 无辉光、无动画 |

## 四、签名视觉元素

### 4.1 HUD 瞄准框 (Corner Brackets)

**这是整个系统的视觉签名。** 每张卡片、每个数据区域的四角都有"L 形角标"，像 HUD 瞄准框/座舱显示器边框：

```css
.hud-frame {
  position: relative;
  border: 1px solid rgba(0,229,255,0.08);
}
.hud-frame::before,
.hud-frame::after {
  content: '';
  position: absolute;
  width: 12px;
  height: 12px;
  border-color: rgba(0,229,255,0.4);
  border-style: solid;
}
.hud-frame::before {
  top: -1px; left: -1px;
  border-width: 2px 0 0 2px;
}
.hud-frame::after {
  bottom: -1px; right: -1px;
  border-width: 0 2px 2px 0;
}
/* 另外两个角用 inner span */
```

```
┌─────────────────────────────────┐
│▌                              ▐│
│   实际内容区域                   │
│   角标是半透明磷光青色 L 形       │
│   像座舱显示器的边框标识          │
│▌                              ▐│
└─────────────────────────────────┘
```

### 4.2 噪声纹理 (Film Grain)

全屏叠加一层极淡的胶片噪声，增加画面深度和质感（不是平面色块）：

```css
.noise-overlay {
  position: fixed;
  inset: 0;
  opacity: 0.015;
  background-image: url("data:image/svg+xml,..."); /* 内联 noise SVG */
  pointer-events: none;
  z-index: 9999;
  mix-blend-mode: overlay;
}
```

### 4.3 示波器扫描线 (Oscilloscope Sweep)

波形图的核心动效 — 曲线从左到右实时绘制，像示波器的扫描过程：

```css
@keyframes scope-sweep {
  0%   { clip-path: inset(0 100% 0 0); }
  100% { clip-path: inset(0 0 0 0); }
}
.waveform-line {
  animation: scope-sweep 1.2s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}
```

### 4.4 全息渐变 (Holographic Sheen)

卡片 hover 时表面滑过一道彩虹全息反光（模拟全息贴纸效果）：

```css
.hud-frame:hover::after {
  background: linear-gradient(
    105deg,
    transparent 40%,
    rgba(0,229,255,0.06) 45%,
    rgba(139,92,246,0.04) 50%,
    transparent 55%
  );
  animation: holo-sweep 0.8s ease forwards;
}
@keyframes holo-sweep {
  0%   { transform: translateX(-100%); }
  100% { transform: translateX(100%); }
}
```

### 4.5 状态指示灯 (座舱风格)

不用 emoji，用纯 CSS 绘制的座舱指示灯：

```
● NOMINAL  → 6px 实心圆 #34D399 + 外圈 glow (0 0 6px)
● CAUTION  → 6px 实心圆 #FBBF24 + 左边框标记
● CRITICAL → 6px 实心圆 #FF2D55 + 脉冲 glow (1.5s infinite)
○ OFFLINE  → 6px 空心圆 #3A4558 (无光)
```

### 4.6 分割线

不是 `<hr>`，是带中心标记的座舱分割线：

```
──────── ◆ ────────
```
中心有一个小菱形标记，线条是 1px 渐变（从透明到 10% 白到透明）。

## 八、技术栈确认

| 层 | 选择 | 理由 |
|----|------|------|
| **前端框架** | React 18 + TypeScript | 生态最大，组件库最丰富 |
| **构建** | Vite | 快速 HMR，比 CRA 快 10 倍 |
| **样式** | Tailwind CSS 4 + CSS 变量 | 原子化 + 主题系统，比 styled-components 更快 |
| **动效** | Framer Motion | React 生态最好的动画库 |
| **图表** | Recharts (sparkline) + Plotly.js (波形) | Recharts 轻量适合小图，Plotly 适合交互式波形 |
| **路由** | React Router v7 | 成熟稳定 |
| **图标** | Lucide React | 轻量、风格统一的 SVG 图标库 |
| **后端** | FastAPI + uvicorn | 封装现有 Python 逻辑为 REST API |
| **通信** | REST (初期) → WebSocket (后期实时推送) | 渐进式升级 |

## 十、启动方式

```bash
# 终端 1: 启动 FastAPI 后端
cd src/api && uvicorn main:app --reload --port 8000

# 终端 2: 启动 React 前端
cd frontend && npm run dev    # → http://localhost:5173

# 或一键启动脚本
python start_ui.py            # 同时启动两个
```

原始 Streamlit 不受影响：`streamlit run src/ui/app.py` 仍然可用。
